# 飞书群内运维机器人

`scripts/feishu_ops_bot.py` 使用飞书官方 SDK 的长连接模式，不需要公开事件回调地址。

## 权限模型

- 只处理 `FEISHU_OPS_ALLOWED_CHAT_IDS` 中群聊发出的消息；
- 群成员可查看运行状态、脱敏日志和错误日志；
- 只有 `FEISHU_OPS_ADMIN_OPEN_IDS` 中的用户能执行 Bot 启停、BREAK 和封禁操作；
- Bot 启停、BREAK 与封禁操作都要求二次确认；
- 一次性请求 ID 会持久化，避免卡片重试或重复点击造成重复操作；
- 日志会丢弃聊天正文，并脱敏 QQ/openid、群 ID、Token、二维码和认证信息。

## 群命令

```text
状态
日志 [1-100]
错误 [1-100]
菜单

重启Bot / 启动Bot / 停止Bot
查询BREAK <QQ号>
发放BREAK <QQ号> <1-100000>
设置BREAK <QQ号> <-1000000 到 1000000>
封禁 <用户ID> <小时，0=永久> [原因]
解封 <用户ID>
```

管理员命令会返回确认卡片；直接点击管理卡片中的按钮也可以启停 Bot。

## 飞书应用配置

在企业自建应用中启用机器人和长连接事件接收，并开通：

- 接收群聊中 `@机器人` 的消息事件 `im.message.receive_v1`；
- 以应用身份发送消息；
- 获取群组信息 `im:chat:readonly`；
- 卡片回传交互 `card.action.trigger`；
- 机器人自定义菜单事件 `application.bot.menu_v6`（使用菜单时）。

可在飞书控制台配置以下菜单事件键：

| 菜单 | event_key |
|------|-----------|
| 运行状态 | `ops_status` |
| 最近日志 | `ops_logs` |
| 最近错误 | `ops_errors` |
| 管理操作 | `ops_admin` |

菜单事件不包含群 ID，因此当前仅响应管理员；普通群成员通过群内命令和卡片按钮操作。

## 服务配置

敏感配置放在服务器 `/etc/maimaidx-feishu-ops.env`，不得写入仓库：

```env
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxx
FEISHU_OPS_ALLOWED_CHAT_IDS=oc_xxx
FEISHU_OPS_ADMIN_OPEN_IDS=ou_xxx
MAIMAIDX_ADMIN_API_URL=http://127.0.0.1:8099/maimaidx/admin/api
MAIMAIDX_ADMIN_API_TOKEN=xxx
FEISHU_OPS_STATE_DB=/var/lib/maimaidx-feishu-ops/actions.sqlite3
```

QueryBot 本身需要启用仅监听本机的 Admin API：

```env
MAIMAIDX_ADMIN_WEB_ENABLED=true
MAIMAIDX_ADMIN_WEB_HOST=127.0.0.1
MAIMAIDX_ADMIN_WEB_PORT=8099
MAIMAIDX_ADMIN_WEB_TOKEN=与运维服务相同的随机管理令牌
```

生产服务应使用独立低权限用户，并只通过 sudoers 放行以下固定命令：

```text
systemctl start maimaidx-bot.service
systemctl stop maimaidx-bot.service
systemctl restart maimaidx-bot.service
```
